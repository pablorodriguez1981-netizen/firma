1 Conexión Sin conectar

Los documentos enviados y los firmados se guardan cifrados en un repositorio privado de GitHub, separado del de esta página. La configuración se hace una sola vez y queda guardada en este navegador.

  1. Crear el repositorio de documentos en github.com/new: nombre firma-datos, visibilidad Private, sin README.
  2. Crear un token en GitHub › Fine-grained tokens, con el vencimiento más largo disponible.
  3. Repository access: Only select repositories, únicamente firma-datos.
  4. Repository permissions › Contents: Read and write.
  5. Copiar el token y pegarlo debajo.

Cada enlace incluye, cifrado, el permiso para guardar el documento firmado en ese repositorio. Por eso el token debe tener acceso únicamente a firma-datos y nunca al repositorio de la página.
