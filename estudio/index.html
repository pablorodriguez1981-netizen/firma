Mandá documentos para firmar

Preparás el PDF, le mandás el link al cliente, él escribe sus datos y firma en el celular, y el documento firmado te llega acá para descargarlo. El cliente no tiene que mandarte nada.

1 Conectar con GitHub Sin conectar

Los documentos (los que mandás y los firmados) se guardan cifrados en un repositorio privado tuyo, aparte del de la página. Se configura una sola vez y queda guardado sólo en este navegador.

  1. Creá el repositorio de documentos: github.com/new › nombre firma-datos › Private › sin README › Create repository.
  2. Abrí GitHub › Generar token (fine-grained token).
  3. Token name: «Firma de documentos». Expiration: la más larga que te deje (por ejemplo, 1 año).
  4. Repository access › Only select repositories › elegí sólo firma-datos.
  5. Permissions › Repository permissions › Contents: Read and write.
  6. Generate token, copialo y pegalo acá abajo.

🔒 Cada link lleva, cifrado, el permiso para guardar el documento firmado en ese repositorio. Por eso el token tiene que tener acceso sólo a firma-datos: nunca al de la página.
